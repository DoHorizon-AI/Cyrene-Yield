# Cyrene Yield contracts / Yield 公开契约 SDK

This independently installable SDK exposes model composition and lineage
identity owned by Cyrene Yield. It depends only on Platform Artifact primitives;
it does not install the Yield training application.

该 SDK 可独立安装，公开由 Cyrene Yield 管理的模型组合和血缘身份。它只依赖
Platform 的 Artifact 基础类型，不会安装 Yield 训练应用。
